# Technical Writing

## Overview

This repository showcases technical documentation for software, APIs, scientific instrumentation, and developer tools. Each sample demonstrates the ability to translate complex technical concepts into clear, actionable content for diverse audiences, from researchers to engineers.

> **For Recruiters:** These samples highlight proficiency in API documentation, schema design, user guides, and information architecture across multiple formats (Markdown, OpenAPI, JSON Schema).

## Projects

| Project | Type | Audience | Key Skills Demonstrated |
| :--- | :--- | :--- | :--- |
| `spectrometer-api/` | API Specification & Schema Design | Developers, Scientists | OpenAPI 3.0, JSON Schema, data modeling, validation documentation |
| `guides/` | Procedural & Conceptual Guides | End Users, Technical Staff | Task-oriented writing, workflow documentation, step-by-step instructions |

## What You'll Find Here

- **Clear structure:** Logical hierarchy with consistent formatting and navigation.
- **Audience awareness:** Tone and depth calibrated to reader expertise.
- **Technical accuracy:** Precise terminology for specialized domains (spectroscopy, APIs, data formats).
- **Multiple formats:** Comfort working across Markdown, YAML, JSON, and structured documentation systems.
